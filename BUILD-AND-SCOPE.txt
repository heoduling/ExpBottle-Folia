Changes:

  debits before delivery, and restores the inventory snapshot/debit on a failed insertion.
- Parse the actual Brigadier args, use PlugManX full target resolution and ignored policy,
  and refuse destructive all/* operations while ExpBottle is enabled.
- Register restored/newly added projectile flights and scan existing entity handles on enable;
  item/validity checks for the enable scan run on the entity scheduler. World-removal and
  impact paths finish counting once. Persisted inactive chunks are not forced to load.
- Native JDK MethodHandle adapters schedule the original manager callback without an old
  ExpBottle invocation frame during construction of a new plugin instance.
- If a manager request finishes without disabling this instance after a completed drain,
  reopen admission and recreate the terminated refund writer. Failed persistence and
  an unfinished drain still refuse the operation and remain paused for explicit retry.
- Rebuild core-owned custom help indexes, including Default, and retain their text,
  permissions, configured names and unrelated topics. Refresh again on enable.
